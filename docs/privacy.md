# 数据与隐私

源笺以个人、自托管使用为主。收藏、研究卡片、摘录与提纲保存于自己的实例，并按账号隔离。公开分享收藏不会开放研究卡片或课题记录。

DOI 元数据查询向 Crossref 发送 DOI，不发送研究笔记或摘录。网页元数据与可选快照会访问所收藏的网站；相关配置见安装说明。

## 本机文件

以下内容只保存在自己的安装中，不提交 Git：

- Windows 数据、账号和密钥：`data/` 与 `local_settings.py`。
- Compose 凭据和数据：`.env` 与 `docker-data/`。
- 内部开发记录与本地工具：`project-notes/`、`.tools/`、`.codex/`、`.agents/`。

备份目录也包含私人资料，请独立保管。反馈问题时只提供已脱敏的日志或截图，不上传数据库、密码、令牌和研究原文。

## 开发与发布

维护者提交使用 GitHub 隐私邮箱。内部评估、个人路径和本机截图不属于发布源码；CI 检查禁止提交本地数据，并扫描 Git 历史中的凭据。

配置 Git 提交邮箱时，可在 GitHub 邮箱设置中查看自己的隐私邮箱，再在此仓库运行 `git config user.email "你的 GitHub 隐私邮箱"`。不要用包含原个人邮箱的公开 `.mailmap` 代替历史清理。

CI 的 Docker 验收只验证本地镜像，不上传构建记录或摘要，并关闭构建元数据中的 provenance；GitHub 推送事件可能带有推送者的个人邮箱，不应作为构建附件或日志公开。发布前也应检查 Actions 日志、附件和缓存，而不仅检查 Git 提交。
